# 更新履歴

### 未公開

- 履修登録の期限・履修単位・時間割・講義カード・詳細ダイアログを，半透明の共通デザインに揃えました．必修・抽選・確定の表示は維持しています．

- 連絡一覧で学情側が青色を指定した未読行だけ，不透明度を通常55%・ホバー時70%にしました．既読行にも付く `is-unread` クラスでは判定しません．

- シラバスの検索前に，空の検索結果パネルの枠が白い線として残る問題を修正しました．

- シラバスの検索・結果一覧・詳細を，半透明のパネルと共通の入力欄・見出し・表のデザインに揃えました．

- 課題・アンケートリストの提出済み行は緑色を保ち，背景を透かしながら見分けられるよう，不透明度を通常55%・ホバー時70%にしました．

- 授業参考情報のパネル・選択欄・見出し・表も，半透明の共通デザインに揃えました．

- ホームで確認した未提出課題の締め切りに合わせ，移動先のページでも背景を切り替えるようにしました．同じタブに保存した締め切り日時から表示直後に判定し，表示中も更新します．

- 講義カードは正方形を基本とし，余白と行間を詰めました．狭い画面で文字が収まらない場合だけ，全曜日の高さを揃えて広げます．

- 講義名は通常の太さにし，講義カードを白40%の背景と薄い黒の1px枠にしました．

- ホームのスケジュールを1〜5コマの位置に揃え，空きコマを空白にしました．講義カードの大きさを統一し，時限・時間，教科名，教室だけを表示します．

### Safari Userscripts版 ver1.12.0

- 通常時・n日未満・1日未満の背景画像を，それぞれ選べるようにしました．
- 警告背景に切り替える日数を設定できるようにしました（初期値3日）．
- 以前の背景画像は通常時の設定として引き継ぎます．
- 横長のヘッダー画像枠をなくし，ウインドウ全体を背景にしました．上部メニューも半透明にし，画像はウインドウのサイズに自動で追従します．背景設定の鉛筆は右下に移しました．
- 背景画像の切り取り位置と拡大率を，保存前に調整できるようにしました．
- 起動時の読み込み完了待ちと固定500msの待機を外し，背景画像とレイアウトを先に反映するようにしました．
- 左側のバーを少し広げ，項目名が途中で改行されないようにしました．
- ホームのお知らせ・スケジュール・成績などを半透明にし，上部の名前・件数・締め切りを一つのパネルにまとめました．
- 学情側の再描画で成績通知スイッチが消える場合に，表示を戻すようにしました．
